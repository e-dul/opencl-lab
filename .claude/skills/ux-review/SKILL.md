# User Experience & Gap Analysis Skill

## Instructions
1. **Gather Context**: Read the specified `README.md` and the associated code files in the module directory.
2. **Simulate Execution**: 
   - Mentally step through every `bash` command and instruction in the README.
   - Verify that all necessary files exist in the exact paths specified.
   - Verify that the cognitive leap between previous modules and this one is fair.
3. **Report Output**: 
   - Do NOT focus on C++ best practices (that is the reviewer's job).
   - Output a list titled "Pedagogical Gaps & UX Friction".
   - Highlight any missing prerequisites, unclear instructions, or jumps in logic.
