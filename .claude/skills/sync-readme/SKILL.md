# Sync README Skill

## Instructions
1. **Read the Source of Truth**: Read the updated `workflow/design/design_[module].md`. Pay special attention to changes in "Roadmap & Status", "Architecture", and "Performance Gates".
2. **Read the Target**: Read the existing `[ModuleFolder]/README.md`.
3. **Apply Updates**: 
   - Modify the README so that its structure, goals, and build steps accurately reflect the new design.
   - Do NOT change the educational tone or remove the mini-challenges unless they contradict the new design.
4. **Save**: Apply the changes directly to the `README.md` file.
