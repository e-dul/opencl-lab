---
description: Generates the student-facing Module README using the @educator subagent.
argument-hint: [module_folder_name]
---
Pass the context "$1" to the @educator subagent. 

Instruct the @educator to use the `readme-creation` skill to generate a complete, student-facing `README.md` inside the "$1" directory. The @educator must follow the project's Education First philosophy and rely on the template specified in the skill.
